# corey-skills

Custom Claude Code skills. Each skill lives in `skills/<name>/SKILL.md`.

## Install

Symlink a skill into `~/.claude/skills/` so edits here stay live:

    ln -s ~/code/corey-skills/skills/<name> ~/.claude/skills/<name>

## Skills

- `design-stack`: runs the full UI design pipeline (ui-ux-pro-max, design-taste-frontend, frontend-design, transitions-dev, web-artifacts-builder, brand-guidelines).
